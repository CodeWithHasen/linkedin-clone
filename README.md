# LinkedIn Clone – React Application

A modern and responsive LinkedIn Clone web application built using React.js, Redux Toolkit, Bootstrap, SCSS, and React Router.

This project recreates the professional LinkedIn user experience with modern UI components, responsive layouts, authentication pages, business tools, premium pages, and interactive social feed functionality.

# Installation

## Clone Repository

```bash
git clone https://github.com/CodeWithHasen/linkedin-clone.git
```

## Navigate to Project

```bash
cd linkedin-clone
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

---

# Build for Production

```bash
npm run build
```

---

# Firebase Deployment

## Install Firebase CLI

```bash
npm install -g firebase-tools
```

## Login to Firebase

```bash
firebase login
```

## Initialize Firebase

```bash
firebase init
```

### Select:

```bash
Hosting: Configure files for Firebase Hosting
```

### Public Directory

```bash
dist
```

### Configure as SPA

```bash
Yes
```

### Deploy Application

```bash
firebase deploy
```
